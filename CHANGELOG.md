# Changelog

## 1.0.0 (2026-10-19)

First release.

- Menu bar gauge for GitHub Actions included minutes, switching to the budget left once they run out.
- Usage tab: minutes used, projected total, reset date, Actions budget with dollars and minutes left, per repository and per runner.
- Runs tab: running, queued, failed in 24h and recent runs, with re-run and cancel.
- Organization and personal accounts, picked from the account menu.
- Uses the `gh` CLI login. No tokens stored.
- `--demo` mode and `scripts/screenshots.sh` for the README images.
